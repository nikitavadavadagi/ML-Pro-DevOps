# ML-Pro: Diabetes Prediction System

## Project Overview

ML-Pro is a Machine Learning based Diabetes Prediction System developed using Flask and Python. The application predicts whether a patient is likely to have diabetes based on medical parameters provided by the user.

## Technologies Used

* Python
* Flask
* Scikit-Learn
* Pandas
* NumPy
* Docker
* Jenkins
* GitHub
* SonarQube

## DevOps Pipeline

The project implements a CI/CD pipeline using:

1. GitHub for source code management
2. Jenkins for Continuous Integration
3. SonarQube for code quality analysis
4. Docker for containerization
5. Docker Hub for image storage

## Features

* User-friendly web interface
* Machine Learning based prediction
* Dockerized application
* Automated build pipeline using Jenkins
* CI/CD Pipeline using Jenkins and Docker
